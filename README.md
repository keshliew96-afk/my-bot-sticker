# my-bot-sticker

Sticker images for 小肥鸟 (the Discord/QQ bird bot). QQ fetches images by public URL, so this repo
serves them via raw.githubusercontent.com.

Layout: `stickers/<category>/<image>.png|jpg|gif|webp`, categories described in `stickers/categories.json`.
Drop images into the category folders and push; the bot picks one at random per category.

Base URL used by the bot: `https://raw.githubusercontent.com/keshliew96-afk/my-bot-sticker/main/stickers`
